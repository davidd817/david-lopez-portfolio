# Content Strategy — Portfolio v2

## Core insight

The original web looked like a Data Analytics / Data Science portfolio built from training projects. That framing is not the strongest route for David's current profile.

The strongest positioning is scientific-technical:

> Materials Characterization & Metrology Scientist bridging advanced instrumentation, nanomaterials and scientific data analysis.

## What changed

### Before

- Data analyst / research scientist hybrid.
- Generic portfolio projects were highly visible.
- Project links led to Google Sites.
- Scientific experience and publications were present but not central enough.

### Now

- Materials characterization and metrology are the main identity.
- Scientific data analysis is positioned as a powerful complementary capability.
- Publications and CSIC experience are central credibility assets.
- Training projects are shown as complementary analytics development, not core professional identity.
- Project links remain inside the new web.

## Recommended public narrative

David works between the laboratory and the data layer: advanced scientific instrumentation, complex experimental datasets and reproducible computational workflows.

## What not to claim

Avoid positioning David as:

- Senior Data Scientist
- Machine Learning Engineer
- AI Scientist
- Senior Analytics Consultant
- Production ML specialist

Better positioning:

- Materials Characterization Scientist
- Metrology Scientist
- R&D Scientist
- Application Scientist — AFM / microscopy / characterization
- Scientific Data Analyst
- Materials Data Analyst
- Research Engineer
- Scientific Computing Specialist

## Google Sites recommendation

Do not use the old Google Sites as the main destination from the new portfolio. It can remain online as an archive, but it should not be linked prominently from the new website.
