# Contributing

This is a personal scientific portfolio. Keep contributions focused, evidence-based and easy to review.

Before opening a pull request:

1. Keep professional and scientific claims consistent with source evidence.
2. Run `npm run lint`, `npm run typecheck` and `npm run build`.
3. Check keyboard access, focus visibility, meaningful alternative text and responsive behaviour for UI changes.
4. Review links, local asset paths, metadata and the complete diff.

Do not add secrets, deployment configuration, unrelated dependency upgrades or generated build output. Vercel deployment is managed outside this repository.
